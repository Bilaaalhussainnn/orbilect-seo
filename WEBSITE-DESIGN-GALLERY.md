# Website Design Gallery release

New page: /website-design-gallery

Uses the existing nine folders in public/industry-showcases, preserving original
filenames and selecting the first 16 images per category in natural numeric order.
The Website Redesign page adds a three-row mixed-industry showcase (24 images
selected across available collections). The new gallery page has nine accessible
industry selectors, responsive two-row collections, the existing ServiceHero,
mobile-design introduction, homepage TechnologyStack, eight FAQs and FinalCta.

SEO includes the canonical, title, description, Open Graph, Twitter card, sitemap,
CollectionPage, ItemList and FAQPage structured data. A Company footer link leads
to the gallery. Naila has direct gallery/template intents, FAQs, page suggestions,
and a build-generated index of the public page.

The exact old demo notice was replaced by the shorter "Sample growth preview".
The counters are still clearly presented as samples, not actual business metrics.

The production build and SEO verification passed 97 sitemap URLs, 458 linked
sections and 154 images. Four obsolete review anchors were corrected to the
review directory. Image-loader checks covered 9 × 16 designs, natural sort,
original filenames and a 24-design mixed selection. Gallery intents were tested.

Your image collections were not uploaded to this workspace. Add or retain the
actual files on your Mac before pushing. Empty collections render a clear text
state rather than broken images. The mixed preview fills automatically from
available collections. To show all nine collections, populate all nine folders.

This package includes the prior industry-showcase and Pinterest changes because
those changes were not yet present in GitHub main when this release was built.
The local installer backs up source files, preserves image files, and does not
commit, push or deploy. Browser visual testing remains outstanding: the managed
preview launcher supplies unsupported Next.js flags. Review on your localhost.
