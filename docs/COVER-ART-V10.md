# Landscape cover prompts — v10

18 covers: 12 industries and all 6 services. Website exports are 960×540 WebP, preserving the complete 16:9 illustration. Generated with the built-in image generator, then compressed using Sharp. No logos, wordmarks, headings or watermarks were requested.

## Shared art direction

Premium matte 3D illustration on white; cobalt blue #004AAD, light grey and graphite detail; restrained soft shadows; thin grey grid fragments; dimensional browser panels; balanced landscape composition with the main scene inside the central 85%. Abstract UI lines and shapes, no readable text, no neon shine. Consistent visual language across the collection.
